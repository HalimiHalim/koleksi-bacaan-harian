# Quran reader data — V2 Mark 3

- Arabic List View: Tanzil Quran Text, Uthmani v1.1, © 2007–2025 Tanzil Project, CC BY 3.0, as stated in the included source file. The original `quran-uthmani-v1.1.txt` is included verbatim with its complete copyright notice. The reader splits its unchanged verses into chapter files. [Tanzil and updates](https://tanzil.net/updates/).
- Malay meanings: Abdullah Basumayyah, *Malay Translation*, QuranEnc.com v1.0.0. The 6,236 translation entries are included verbatim, without editing, from QuranEnc's versioned archive. Publisher: Basair Endowment for serving the Noble Quran and its Sciences. [Translation and terms](https://quranenc.com/en/browse/malay_basumayyah) · [API and republication conditions](https://quranenc.com/en/home/api). Review for source updates before each future Quran release; report translation notes to QuranEnc.
- Page boundaries and line grouping: `quran-qcf4` JSON layout © 2026 Mohamad Hajj Rabee (MIT), derived from the King Fahd Quran Printing Complex Madinah Mushaf. The full upstream [JSON license and font notice](QCF4-LICENSE.md) are included. Only JSON metadata and its Arabic word text are used. **Its restricted font files are not bundled or loaded.** [Layout source](https://github.com/MohamadHajjRabee/quran-qcf4).
- Rendering: existing bundled Noto Naskh Arabic (SIL OFL 1.1); verse-end numbers are separate themed UI elements. The page and line boundaries follow the 604-page Madinah layout, though Unicode font spacing cannot promise a pixel-identical printed page.

Generated by `tools/build_quran_data.py` from pinned source snapshots. Quran text and translations are data: do not edit them while changing the UI.
