- Page boundaries and line grouping: `quran-qcf4` JSON layout © 2026 Mohamad Hajj Rabee (MIT), derived from the King Fahd Quran Printing Complex Madinah Mushaf. The full upstream [JSON license and font notice](QCF4-LICENSE.md) are included. Its word positions are paired, in verse order, with the full Tanzil Uthmani text including madd and pause marks; the source's standalone basmalas are displayed without an ayah number except for Al-Fatihah. The build replaces 15 `#1969` font placeholders with the Unicode sajdah sign `۩`; page boundaries and line grouping remain intact. **Its restricted font files are not bundled or loaded.** [Layout source](https://github.com/MohamadHajjRabee/quran-qcf4).
- Rendering: existing bundled Noto Naskh Arabic (SIL OFL 1.1); verse-end numbers are separate themed UI elements. The page and line boundaries follow the 604-page Madinah layout, though Unicode font spacing cannot promise a pixel-identical printed page.

Generated by `tools/build_quran_data.py` from pinned source snapshots. Quran text and translations are data: do not edit them while changing the UI.

## V2.5 Simple Arabic script

- **Representation:** Tanzil **Simple (Imla’ei), version 1.1, with diacritics**. Downloaded 2026-09-30 directly from [Tanzil](https://tanzil.net/download/) with pause marks, sajdah signs and tatweel enabled; rub-el-hizb option disabled. [Exact request](https://tanzil.net/pub/download/index.php?quranType=simple&outType=txt-2&marks=true&sajdah=true&tatweel=true&agree=true). UTF-8 snapshot `scripts/simple/quran-simple-v1.1.txt`, SHA-256 `c8c2ea9e004cf3f4b7afc5ba00de859556f4ed09bd9cf5d1bc79e877406ef678`.
- **License:** © 2007–2026 Tanzil Project, CC BY 3.0 and publisher [verbatim redistribution conditions](https://tanzil.net/docs/text_license). The complete publisher notice remains unchanged in the raw snapshot and is reproduced as `copyrightNotice` in **every** derived surah JSON. Every stored verse is byte-for-byte text-equivalent to its source; no normalization or conversion from Uthmani. Existing in-app Tanzil attribution/link applies to both scripts. Review [updates](https://tanzil.net/updates/) before future releases.
- **Packaging:** `tools/build_quran_scripts.py` packages immutable text by surah, and `--verify` checks all output bytes, source hash, identities and page mapping. `scripts/script-alignment-report.json` records all 6,236 identities, 604 pages, Unicode inventory and exact source. Raw snapshot and report are audit assets, not startup downloads. Per-surah JSON is lazy-loaded and cached by the service worker; the reader retains at most eight Simple chapters in memory. Offline use requires visiting the applicable page/surah online first, as with existing Quran assets.
- **Structure:** 112 unnumbered intro basmalahs (all surahs except 1 and 9). Al-Fatihah's 1:1 stays numbered; surah 9 has no intro. Surahs 95 and 97 retain their source initial shadda. The baseline verifier prints “111” but its asserted set and actual Page View tokens contain 112; the protected verifier is unchanged. Separating a source prefix for display does not change the stored verse. All 15 source sajdah signs and pause marks remain in place; verse-end numbers are separate UI markers. No ayah-end digits/symbols are stored in Simple source.
- **Page View:** full Simple verses follow the existing `verse-pages.json`/QCF end-marker page assignment and structural heading/basmalah sequence, with continuous RTL flow at 32px. This preserves the app's 604-page verse identity; it does not claim printed Simple mushaf word/line pagination. For verses crossing a Uthmani page boundary, the whole Simple verse is shown on its assigned end-marker page. QCF word positions and quarter markers are not projected onto Simple text. Uthmani's word flow, quarter marks, Tajweed and page-hash checks remain unchanged.
- **Font:** existing Noto Naskh Arabic variable TTF, 307,592 bytes, SIL OFL 1.1 (`fonts/OFL.txt`); cmap audit covers all 55 Simple corpus code points. No font file added or changed.
- **Tajweed:** Uthmani only. Simple is plain and its controls disabled; the separate Uthmani ON/OFF preference is retained and restored on return.
- **IndoPak:** deferred because dataset-specific redistribution licensing remains unresolved. No IndoPak dataset, font, runtime fetch or UI option is included. Future V2.5.1 requires a separate license/data/font audit; the current identity adapter can be extended without rewriting Uthmani.
